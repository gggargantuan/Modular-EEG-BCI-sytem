# Modular-EEG-BCI-sytem

This repository contains the firmware for a BCI system based on modular EEG hardware. The firmware is designed to send binary data over to Python Lab Streaming Layer (LSL) bridge middleware, which can be used for visualisation in software like OpenViBE.

The EEG device is designed as a low-cost, open-hardware module using commercially available off-the-shelf (COTS) components. The system supports up to 8 channels with a resolution of 16 to 24 bits and a sampling rate of up to 1 kHz, featuring instrumentation amplifiers, active shielding and noise rejection, as well as wireless connectivity for real-time signal recording and visualisation.
